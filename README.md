# PowerBI-Sales-Performance-Dashboard
A sales data visualization project using Power BI to analyse sales performance, order trends, product revenue and customer payment patterns

# Project Overview
This project focuses on data visualization using Power BI to explore sales performance and communicate business insights through an interactive dashboard.

# Tools Used
- Microsoft Power BI
- Power Query
- DAX
  
# Project Objectives
- Visualize sales performance across products.
- Analyse monthly sales trends.
- Examine order distribution by status.
- Understand customer payment method preferences.
- Present key business metrics through an interactive dashboard.

# Key Performance Indicators
- Total Sales: $1,264,761.96
- Total Orders: 1,200
- Average Order Value: $1,053.97

# Visualizations Created
1. Sales Performance by Product
2. Monthly Sales Trend
3. Order Distribution by Status
4. Orders by Payment Method
5. Revenue by Order Status

# Interactivity
The dashboard includes a date range slicer that allows users to filter the report and explore sales performance across different periods.

# Project Files
- Power BI dashboard (.pbix)
- Dashboard export (.pdf)

# Conclusion
This project demonstrates the use of Power BI to transform sales data into meaningful visual insights, supporting better understanding of business performance and trends.
